This project pulls historical stock data using the Alpha Vantage API, cleans and transforms it using Python, and visualizes it through an interactive dashboard in Power BI.

---

## Tools Used
- Python (pandas, requests)
- Power BI Desktop
- Alpha Vantage API
- VS Code + Git

---

## Features
- Pulls stock data for AAPL and TSLA using API
- Cleans and formats the data with pandas
- Converts daily stock prices to a Power BI-ready format
- Interactive dashboard:
  - Line chart with closing prices
  - Time slicers
  - Symbol filters (AAPL vs TSLA)
